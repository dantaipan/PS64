PS64 1.0.1: latest releases from Assembly64, and fixes.

## New

- Search Assembly64: press R1 to see the 25 latest releases, newest first with their release dates. It shows the category chosen with L2, or games when none is chosen.
- Search results use the whole screen: 20 rows instead of 10 once you're in the list (Search files and Search Assembly64).
- Search Assembly64 shows a screenshot of the highlighted release beside the results, for releases from CSDb (thanks to csdb.dk).

## Fixes

- Starting a disk on a C64 Ultimate now loads from whatever device number the Ultimate's Drive A is set to (not always 8), so it also works when a real disk drive uses 8.
- Assembly64 names with special characters show properly ("Hello <3" instead of "Hello &lt;3").
